# FRI paper summary

[Fast Reed-Solomon Interactive Oracle Proofs of Proximity - Ben-Sasson, Bentov, Horesh, Riabzev (ICALP 2018)](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.ICALP.2018.14)

**FRI** is an **Interactive Oracle Proof of Proximity ([IOPP](posts/zk/zk-terminology.md#interactive-oracle-proof-of-proximity-iopp))** for [Reed–Solomon codes](posts/zk/zk-terminology.md#reed-solomon-code). It achieves **strictly linear** prover [arithmetic complexity](posts/zk/zk-terminology.md#arithmetic-complexity) and **logarithmic** verifier complexity, improving on prior [RS-IOPPs](posts/zk/zk-terminology.md#reed-solomon-interactive-oracle-proof-of-proximity-rs-iopp)/[PCPPs](posts/zk/zk-terminology.md#probabilistically-checkable-proof-of-proximity-pcpp) that required super-linear proving time. The name reflects its resemblance to the [FFT](posts/zk/zk-terminology.md#fast-fourier-transform-fft) and its strictly linear (not just quasi-linear) prover cost.

## Motivation

- Reed–Solomon (RS) codes are central to quasilinear [PCPs](posts/zk/zk-terminology.md#probabilistically-checkable-proof-pcp) and [IOPs](posts/zk/zk-terminology.md#interactive-oracle-proof-iop) with polylogarithmic verifiers. The **concrete cost of proving** RS membership was a major obstacle to deploying such systems.
- Prior RS-IOPPs and PCPPs required super-linear proving time even for polynomially many queries.

## Main results

1. **Complexity**  
   For block-length $N$: prover arithmetic complexity $< 6N$; verifier arithmetic complexity $\leq 21 \log N$; query complexity $2 \log N$; constant soundness - words $\delta$-far from the code are rejected with probability $\min\{\delta(1 - o(1)), \delta_0\}$ for a constant $\delta_0$ depending mainly on the code rate.

2. **Soundness vs prior work**  
   The combination of query complexity and soundness is better than the quasilinear PCPP of [BS08] even with the tighter analysis of [Ben-Sasson et al., STOC 2013], so FRI enables more concretely efficient ZK proof and argument systems.

3. **Composition**  
   When $\delta$ is below the unique decoding radius, FRI suffers only **negligible additive** soundness loss per round (unlike prior systems with constant multiplicative loss per round). This allows $\Theta(\log N)$ composition rounds instead of $O(\log \log N)$.

## Technical core

- **Folding:** The prover commits to a sequence of “folded” polynomials; each round reduces the domain size by a constant factor. The verifier checks consistency along a random path. The structure mirrors a Cooley–Tukey style FFT.
- **Soundness:** Analysis shows that if the initial word is far from the RS code, then with high probability either a consistency check fails or the final polynomial is not low-degree.

## Efficiency and impact

- **Prover:** $O(N)$ field operations (strictly linear).
- **Verifier:** $O(\log N)$ field operations and $O(\log N)$ queries.
- FRI is the low-degree test underlying transparent systems such as STARK, Aurora, and later DEEP-FRI; DEEP-FRI improves soundness while keeping the same complexity profile.

> FRI is the first RS-IOPP with linear prover and logarithmic verifier, enabling practical transparent ZK systems. It is superseded in soundness by DEEP-FRI but remains the core proximity test in deployed STARK-style protocols.
